# Muhammad Noman - Personal Portfolio

A modern, production-ready personal portfolio website built with React, Vite, and Tailwind CSS featuring dark theme, glassmorphism design, and smooth animations.

![Portfolio Preview](public/preview.png)

## ✨ Features

- 🎨 **Modern Design**: Dark theme with cyan-to-purple gradient accents
- 🪟 **Glassmorphism**: Beautiful frosted glass cards with hover animations
- 📱 **Fully Responsive**: Mobile-first design with hamburger menu
- ⚡ **Smooth Animations**: Scroll-triggered animations using Framer Motion
- 🔗 **Smooth Scroll**: Seamless navigation between sections
- ♿ **Accessible**: Semantic HTML and keyboard navigation support
- 🚀 **Optimized**: Code splitting, lazy loading, and production builds

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS v3
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Routing**: React Router DOM (for smooth scroll)
- **Build**: Vite with optimized production config

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/muhammad-noman-portfolio.git
cd muhammad-noman-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
